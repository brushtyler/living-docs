# Living Docs

For documentation updates, use the Living Docs MCP workflow: run `doctor`,
check staleness, resolve routes for UI source changes, validate recipes, and
review a sync plan before capture or apply. Treat diagnostic and planning tools
as read-only. Ask before mutating tools when permission has not already been
granted. Never expose typed credentials, cookies, or session state, and never
broaden allowed origins or the output root without explicit approval.
